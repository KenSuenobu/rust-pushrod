# Pushrod Agents

## When work completes

- Mark the item complete in any roadmap files that reference the issue.
- Order of Execution document must be marked.
- Documentation must be written.
- Lint must pass.
- Docusaurus must build.
- Any diagrams for Docusaurus must be shown using mermaid diagrams.
- Any new behavior introduced as the result of a ticket should be added to a test application for validation.
- Add a one line note to the CHANGELOG file indicating the fix in the format: [#(ticket ID)] One sentence summary of work [(username)]
- !IMPORTANT! NO WARNINGS OR ERRORS IN THIS PROJECT - WARNINGS IN 3RD PARTY LIBRARIES ARE ACCEPTABLE, AS THEY ARE OUT OF OUR CONTROL

## DO NOT

- Modify any files outside of the scope of the ticket.
