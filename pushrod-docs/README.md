# pushrod-docs

The Pushrod documentation site, built with [Docusaurus](https://docusaurus.io).

```bash
npm install
npm start        # live preview at http://localhost:3000/rust-pushrod/
npm run build    # production build; broken links fail the build
```

- Pages live in `docs/`. Each widget has its own page in `docs/widgets/`, grouped under **Widgets** in the sidebar.
- Screenshots live in `static/img/screenshots/`.
- See `docs/writing-documentation.md` (published as "Writing documentation") for the page template, where pages go, and the sample-data rule.
